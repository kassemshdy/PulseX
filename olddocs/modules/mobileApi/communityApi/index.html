    Community API

    Usually, the subdomain of community API is engage, e.g:

    https://engage.alittihad.ae

    The HTTP responses returned are: - 200 for successful response. - 401 for unauthorized user. - 500 for unexpected exception, usually when missing or wrong parameters are used.

    The response is JSON encoded.

    IsAuthorized API

    GET /user/is_authorized
    Type Parameters Description Required
    Request headers id User id true
    key User key true
    Response body name User full name
    status 200 if authorized

    User Registration

    Post /user/mobile_register
    Type Parameters Description Required
    Request headers email User email address true
    password User password true
    mobile_key A key generated by the mobile app true
    body firstname User first name
    lastname User last name
    country User country
    phonenumber pone number
    birthdate birth date
    Response status 200 sucess
    400 if missing parameters
    403 if user already exists

    Login

    Post /v2/user/login
    Type Parameters Description Required
    Request body Username User email address true
    Password User password true
    Response body id User id
    key User key
    name User full name
    tokens: { AccessToken {Token, Expires}, RefreshToken, Success }
    status 400 if missing parameters
    401 if non-existing user or wrong password
    403 if inactive/pending account

    After successfully logging in, please save the access token and refresh token, because it will be used with other secure APIs.

    Logout

    When logging out, make sure you delete the access token and refresh token.

    Refresh Token

    Post /v2/user/refreshtoken
    Type Parameters Description Required
    Request body RefreshToken user current refresh token true
    AccessToken User current access token true
    Response body RefreshToken user new refresh token
    AccessToken user new access token
    status

    The RefreshToken API is used when calling any secure API (change password,...) and we get 401, this means that token has expired. So, we use this API to get new tokens. Then, send a request to the secure API again with the new access token.

    NOTE: When you receive 401, that means the refresh token has expired, and you need to redirect the user to the login page.

    Get User Profile API (secure API)

    Post /v2/user/getinfo
    Type Parameters Description Required
    Request headers Authorization Bearer{space}{access_token} true
    Response email User email
    fullname User full name
    firstname User first name
    lastname User last name
    country User country
    gender User gender
    10: male
    20: female
    phonenumber User phone number
    birthdate User birth date
    status 400 if missing parameters

    Edit User Profile API (secure API)

    Post /v2/user/updateinfo
    Type Parameters Description Required
    Request headers Authorization Bearer{space}{access_token} true
    body firstname User first name true
    lastname User last name true
    country User country
    gender User gender
    10: male
    20: female
    phonenubmer phone number
    birthdate User birth date
    Response status 400 if missing parameters

    Change Password API (secure API)

    Post /v2/user/changepassword
    Type Parameters Description Required
    Request headers Authorization Bearer{space}{access_token} true
    body oldpassword User old password true
    newpassword User new password true
    email User email address true
    Response status 401 if unauthorized

    Forgot Password API

    Post /user/recover
    Type Parameters Description Required
    Request headers email User email true
    Response status 400 if missing parameters if inactive account

    This action sends an email to the user containing a URL which includes the code parameter. This parameter will be used in the Update Forgotten Password API.

    Update Forgotten Password API

    Post /user/update_password
    Type Parameters Description Required
    Request headers password User new password true
    code User code true
    Response status 400 if missing parameters if inactive account

    Check if User Exist API

    GET /users/usernameexists
    Type Parameters Description Required
    Request URL username User email true
    Response true/false
