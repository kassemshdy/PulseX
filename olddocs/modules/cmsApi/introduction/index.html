    Introduction

    The CMS API is a module that enable third parties to create and publish posts without using the default CMS.

    To use the CMS API it is required to have the subscriptionCode and the postTypeCode.

    Examples of subscriptionCode:

    • alitihad for alittihad.ae.
    • zak for zahratalkhaleej.ae.

    Examples of postTypeCode:

    • news for alittihad.ae.
    • article for zahratalkhaleej.ae.

    NOTE: The postTypeCode should be requested from the Admin administrators.
