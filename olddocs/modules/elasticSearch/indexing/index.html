    Indexing

    The following are the steps to create an index and index the existing data.

    We may add other words to this file using the two APIs below (for better search results):

    Update Meta API

    POST /keywords/update_meta
    Type Parameters Description Required
    Request body file Keywords file name true

    The keywords file name is the full path of the keywords file. For example:

    D:/elasticsearch-6.5.1/elasticsearch-6.5.1/config/keywords.txt

    Update Titles API

    POST /keywords/update_titles
    Type Parameters Description Required
    Request body file Keywords file name true

    Index Creation API

    To create an index with Arabic language.

    POST /indices
    Type Parameters Description Required
    Request body index index name true
    keywords keywords file name
    language 10: arabic
    30: english    		 true

    NOTE: The keywords file is the text file located in the config folder inside the ElasticSearch folder containing words that shouldn’t be stemmed.

    Example:

    { "index": "ar", "keywords": "keywords.txt", "language": 10

    Index Existing Data API

    POST /documents/add_saved
    Type Parameters Description Required
    Request body index index name true
    from The page number from which we start saving data, 1 by default
    to The last page number from which we save data
    fromdate The date from which we start saving data. (YYYY/MM/dd)
    todate The date which won’t be exceeded. (YYYY/MM/dd)
    body List of excluded post type codes

    Make sure you send the following body parameter: (in addition to all types that shouldn’t be indexed):

    ["templates"]

    Index Generated Data API

    POST /documents/add_generated
    Type Parameters Description Required
    Request url index index name true

    That’s how you save existing data in your index.

    Newly created posts will be automatically indexed once published, and will no longer be indexed when withdrawn.

    Docs Count API

    GET /indices/{name}/get_docs_count
    Type Parameters Description Required
    Request url name index name true
    Response count Number of documents

    Docs Count API

    GET /indices/{name}/get_client_docs_count
    Type Parameters Description Required
    Request url name index name true
    Response count Number of documents

    Delete Index API

    POST /indices/{name}/delete
    Type Parameters Description Required
    Request url name index name true

    Delete Subscription' Documents API

    POST /documents/delete_client_docs
    Type Parameters Description Required
    Request url name index name true

    Re-index Documents API

    In case, the keywords file has changed, and you want to consider the newly added keywords, make sure you re-index the existing data with this API.

    POST /indices/{name}/reindex
    Type Parameters Description Required
    Request url name index name true
    body keywords keywords file name true
    language 10: arabic
    30: english    		 true

    Re-index Documents API (Internal)

    Another API is called on daily basis to re-index failed documents.

    POST /documents/reindex
    Type Parameters Description Required
    Request url index index name true
    size The count of las posts published to be re-indexed true
    overwrite Overwrite already indexed posts or not
