**Epic:** Media Library
**Status:** backlog

## Description

As a content editor, I want to browse, search, and manage media files, so that I can find and reuse assets easily.

## Acceptance Criteria

- [ ] GET /api/media lists media with pagination
- [ ] Can filter by type, date, tags
- [ ] Can search by filename or alt text
- [ ] Can update media metadata
- [ ] Can delete media (soft delete)
- [ ] Returns CDN URLs for files
