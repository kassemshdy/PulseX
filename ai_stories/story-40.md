# Story story-40: Build User Authentication System

**Epic:** PulseX Platform
**Status:** todo
**Priority:** critical
**Estimate:** 8h
**Assignee:** Unassigned

## Description

As a user, I want to log in and out securely, so that I can access my admin panel.

## Acceptance Criteria

- [ ] Login form with email and password
- [ ] JWT token generation on successful login
- [ ] Token stored securely in httpOnly cookie
- [ ] Logout clears tokens
- [ ] Password reset via email
- [ ] Session expiry after 7 days
- [ ] Remember me option

## Technical Tasks

- [ ] Create login API endpoint
- [ ] Implement password verification
- [ ] Generate access and refresh tokens
- [ ] Set httpOnly cookies
- [ ] Create logout endpoint
- [ ] Implement password reset flow
- [ ] Add token refresh logic
- [ ] Build login UI form
