## Technical Details

### Subdomain Auto-Generation
**Format:** `{email-prefix}-{timestamp}`
**Example:** `test-lk3j4h5`

**Code:**
```typescript
const subdomain = data.subdomain || 
  `${email.split('@')[0].replace(/[^a-z0-9]/g, '')}-${Date.now().toString(36)}`;
```

### Database Schema
Still uses the subscription model, but subdomain is hidden from users:
- Each user gets a subscription
- Subscription has auto-generated `code` (subdomain)
- User can later add custom domain if needed
